# ช่องทางติดต่อทีม DoBao ผ่านเว็บ

ผู้ใช้เข้าสู่ระบบแล้วเปิด บัญชี → ติดต่อทีม DoBao หรือ `https://dobaohealth.vercel.app/#support` ส่งข้อความและอ่านคำตอบในหน้านี้ได้ ข้อมูลแยกตามเจ้าของบัญชี ใช้ได้แม้ถอน health/AI consent ไม่มีการส่งข้อความให้โมเดลโดยอัตโนมัติ ไม่มีอีเมลหรือ push notification ทีมต้องตรวจคำขอและตอบจริงตามกระบวนการของทีม

ติดตั้ง `supabase/migrations/007_support_requests.sql` ก่อน เพิ่มตารางอย่างเดียว ไม่ลบข้อมูลเดิม

ทีมที่มีสิทธิ์ผู้ดูแลโปรเจกต์เปิด Table Editor → `dobao_support_requests` กรอง `status = new` อ่านคำขอ แล้วกรอก `reply`, เปลี่ยน `status = answered`, ตั้ง `answered_at` เป็นเวลาปัจจุบันในรูปแบบ ISO ผู้ใช้กด “ตรวจคำตอบล่าสุด” จะเห็นคำตอบ การใช้ Table Editor เป็นงานผู้ดูแลเท่านั้น ไม่เปิด service-role key หรือหน้า Dashboard ให้ผู้ใช้ทั่วไป

ผู้ใช้ทั่วไปอ่าน/ลบเฉพาะข้อความของตัวเอง และเพิ่มได้เฉพาะ topic/message/user_id ที่ตรวจ RLS ไม่แก้ไขคำตอบหรือสถานะของทีมได้ ข้อความไม่อยู่ในปุ่ม “ลบสุขภาพทั้งหมด” แต่ผู้ใช้ลบแต่ละข้อความในหน้าติดต่อได้ และดาวน์โหลดใน account export ได้

ช่องทางนี้ต้องเข้าสู่ระบบ ถ้าต้องการรองรับผู้ที่เข้า Google ไม่ได้หรือไม่ได้มีบัญชี ต้องเพิ่มช่องทางจริงสำหรับผู้ใช้กลุ่มนั้นก่อนอ้างว่ารองรับทุกคำขอ
